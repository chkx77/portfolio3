# Portfolio de Matías Romero

Presentación profesional orientada a desarrollo web, soporte e implementación, con cuatro proyectos personales y académicos seleccionados.

## Tecnologías
React 19, JavaScript, CSS y Lucide. El proyecto conserva el entorno de Create React App.

## Desarrollo
Node.js 22 y npm.

```sh
npm install
npm start
npm test -- --watchAll=false
npm run build
```

## Contenido
Ferretería PRO, Agenda Pro, Cuentas Claras y Gestión de empleados. Cada tarjeta incluye alcance, tecnologías, límites y enlace al código. Se mantienen enlaces a demos existentes; sus actualizaciones requieren comprobar el despliegue correspondiente.

No hay pantalla de carga artificial ni tarjeta de proyecto vacío. Navegación con teclado, enlace al contenido, etiquetas de formulario y diseño para pantallas pequeñas. El contacto abre un borrador en la aplicación de correo del visitante y no envía mensajes automáticamente.

## Publicación
En Vercel seleccionar el proyecto existente, comando `npm run build` y carpeta `build`. Mantener una única URL principal de portfolio en GitHub y CV.
